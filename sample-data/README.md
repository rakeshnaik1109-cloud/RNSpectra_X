# Sample data

Drop a few small, shareable spectra here so anyone opening the repository can
try the app immediately — for example:

```
sample-data/
├── demo_control_01.txt
├── demo_control_02.txt
├── demo_treated_01.txt
└── demo_treated_02.txt
```

Two files per group is enough to demonstrate group averaging with error bands.

Keep unpublished experimental data out of the repository; `.gitignore` already
excludes `sample-data/private/`.
